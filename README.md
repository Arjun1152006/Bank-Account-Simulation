# Bank Account Simulation  

## Overview  
This is a simple Java program that simulates basic bank operations using **Object-Oriented Programming (OOP)**.  
It allows users to deposit money, withdraw money, check balance, and view transaction history.  

---

## Features  
- Create an account with an initial balance  
- Deposit money  
- Withdraw money (with validation)  
- Check account balance  
- View transaction history  
- Menu-driven interface  

---

## How to Run  

1. Save the file as **BankSimulation.java**  
2. Open the terminal in the project folder  
3. Compile the program:  
   ```sh
   javac BankSimulation.java
